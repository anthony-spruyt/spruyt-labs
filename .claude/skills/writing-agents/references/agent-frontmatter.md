# Agent Frontmatter Field Reference

| Field             | Format                                                                        | Notes                                                                                                                                                                                                                                                            |
| ----------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`            | lowercase, numbers, hyphens                                                   | Unique. No `:` (reserved for plugin scope) and no leading `-`; Claude Code skips files that break either rule                                                                                                                                                    |
| `description`     | string                                                                        | When the parent should delegate. Loaded into every parent request; the body loads only when the agent runs. Project cap 1024 chars (Claude Code warns when all custom descriptions together exceed 15,000 tokens). See the Description Field section in SKILL.md |
| `model`           | `opus` / `sonnet` / `haiku` / `fable` / full model ID / `inherit`             | Optional. A `model` passed on the Agent call overrides it. Omitted: `CLAUDE_CODE_SUBAGENT_MODEL` if set, else the main session's model. See `project-patterns.md` Section 2 |
| `effort`          | `low` / `medium` / `high` / `xhigh` / `max`                                   | Optional. Overrides the session effort for this agent; omitted inherits it. Available levels depend on the model. See `project-patterns.md` Section 2                                                                                                            |
| `tools`           | comma-separated string or list                                                | Optional. Omit for all tools. Prefer least privilege. Accepts `mcp__<server>__*`                                                                                                                                                                                 |
| `disallowedTools` | same as `tools`                                                               | Optional. Removed before `tools` is resolved; `Bash(git push *)` removes the whole Bash tool                                                                                                                                                                     |
| `permissionMode`  | `default` (alias `manual`) / `acceptEdits` / `auto` / `dontAsk` / `bypassPermissions` / `plan` | Optional. Ignored when the parent runs in `bypassPermissions`, `acceptEdits`, or auto mode. A declared `bypassPermissions` takes effect only when the parent already bypasses |
| `maxTurns`        | integer                                                                       | Optional. Limit agentic turns; output is returned marked partial                                                                                                                                                                                                 |
| `skills`          | list of skill names                                                           | Optional. Preloads each skill's full content at startup; unlisted skills stay invocable                                                                                                                                                                          |
| `mcpServers`      | list of server names or inline definitions                                    | Optional. MCP servers available                                                                                                                                                                                                                                  |
| `hooks`           | hook config object                                                            | Optional. Agent-specific hooks; `Stop` runs as `SubagentStop`                                                                                                                                                                                                    |
| `memory`          | `user` / `project` / `local`                                                  | Optional. Enables agent memory directory; `project` is the recommended scope                                                                                                                                                                                     |
| `background`      | boolean                                                                       | Optional. Run in background                                                                                                                                                                                                                                      |
| `isolation`       | `worktree`                                                                    | Optional. Run in isolated worktree                                                                                                                                                                                                                               |
| `color`           | `red` / `blue` / `green` / `yellow` / `purple` / `orange` / `pink` / `cyan`   | Optional. UI color                                                                                                                                                                                                                                               |
| `initialPrompt`   | string                                                                        | Optional. First user turn when the agent runs as the main session (`--agent`)                                                                                                                                                                                    |
| `omitClaudeMd`    | boolean                                                                       | Optional. `true` starts the agent without the user, project, and local CLAUDE.md files, project rules included. Only for agents that take everything from the delegation prompt; this project's agents rely on inherited rules |
| `experimental`    | map                                                                           | Optional. `cacheTtl: 5m` or `1h` sets this agent's prompt-cache lifetime                                                                                                                                                                                         |

Field names are camelCase and must match exactly: Claude Code silently ignores a field it doesn't recognize.
